Community Contribution Workflow

Submit a Model to the Leaderboard

1 Fork & Clone the Repository

Fork the leaderboard repository to your personal GitHub account and clone it to your evaluation machine:

git clone https://github.com/<your-username>/llm-auto-benchmark-leaderboard.git
cd llm-auto-benchmark-leaderboard
2 Run the Evaluation Suite Locally

Run the automated benchmark harness with your model ID or local weights path:

# Example running evaluation for an open-weight model:
python -m slm_bench.evaluate \
  --model-id "Qwen/Qwen2.5-7B-Instruct" \
  --quantization "GGUF_Q4_K_M" \
  --backend llama.cpp \
  --benchmarks gsm8k,humaneval,arc,ifeval,tool_calling \
  --output-dir ./data/results/
3 Drop the Generated JSON into /data/results/

The harness automatically generates a standard JSON file named <organization>_<model_slug>.json in data/results/. Verify it contains hardware telemetry and sample run logs.

4 Commit, Push & Open Pull Request

Create a feature branch, commit your result file, push to your fork, and submit a PR:

git checkout -b submit/qwen-2.5-7b
git add data/results/Qwen_Qwen2.5-7B-Instruct-GGUF_Q4_K_M.json
git commit -m "feat(benchmark): add Qwen2.5-7B-Instruct evaluation"
git push origin submit/qwen-2.5-7b

Our GitHub Actions CI will automatically validate your submission against schema rules, verify small local AI criteria (reviewed by maintainer), and re-aggregate the leaderboard on merge!

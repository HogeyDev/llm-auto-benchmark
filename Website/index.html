03 Contribute

Run it on your machine. Send the receipt.

The harness records your GPU, VRAM, CPU, RAM, OS, driver, and tokens per second beside the scores. A result without hardware context is an opinion, not a measurement.

  1. 1
    Install the harness

    Python 3.10+. Install the extra for whichever backend you use.

  2. 2
    Point it at a model

    Native llama.cpp, vLLM, transformers, or any OpenAI-compatible server such as Ollama or LM Studio.

  3. 3
    Open the pull request

    The JSON lands in website/data/results/. CI checks the schema and the board republishes on merge.

# Ollama, LM Studio, vLLM, LocalAI — anything OpenAI-compatible
slm-bench evaluate \
  --model-id "qwen2.5-coder:7b" \
  --backend openai \
  --endpoint-url "http://localhost:11434/v1" \
  --model-ram-gb 4.8 \
  --notes "RTX 3060 12GB, 33 layers on GPU"

Contribution workflow

Submit a model

One result file, one pull request. No account on this site.

1Fork and clone

Fork the repository to your account, then clone your fork.

git clone https://github.com/<your-username>/llm-auto-benchmark.git
cd llm-auto-benchmark
2Run the evaluation

Use the model where it actually lives: llama.cpp, vLLM, transformers, or a local OpenAI-compatible server. Record the footprint.

slm-bench evaluate \
  --model-id "qwen2.5:7b" \
  --backend openai \
  --endpoint-url "http://localhost:11434/v1" \
  --model-ram-gb 4.8 \
  --notes "Ollama on RTX 3060 12GB"
3Keep the result file

The harness writes to website/data/results/<model-slug>.json. Check that the GPU, VRAM, CPU, RAM, OS, and tokens/sec are present. Incomplete telemetry gets sent back.

4Commit and open the PR

Branch, commit, push, and open a pull request. CI validates the schema; a merge republishes the static board.

git checkout -b submit/qwen-2.5-7b
git add website/data/results/Qwen_Qwen2.5-7B-Instruct-GGUF_Q4_K_M.json
git commit -m "feat(benchmark): add Qwen2.5-7B-Instruct evaluation"
git push origin submit/qwen-2.5-7b

Paste a generated result file to check the required fields before opening the PR.

Paste this into the pull request description.
